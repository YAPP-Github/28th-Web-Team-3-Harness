# 미션 입력 및 AI 미션 생성 플로우

- ID: FLOW-MISSION-001
- 참여자: 사용자, 클라이언트, 미션 서비스, 네이버 블로그 검색, AI
- 시작 조건: 생년월일·거주지역을 포함한 온보딩을 완료한 사용자가 AI 미션 추가를 시작함
- 종료 상태: 선택 가능한 AI 미션 후보가 생성되었거나 생성 작업 실패가 반환됨

## 정상 흐름

1. 클라이언트가 식사·생활·취미와 각 항목 목록을 보여준다.
2. 사용자가 카테고리와 항목 하나, 주간 빈도 1~10회, 주간 금액 1~2,000,000원을 입력한다.
3. 서버가 항목의 고정 검색 문구에 사용자의 만 나이 연령대와 거주지역을 결합한다.
4. 네이버 블로그 검색 결과 중 설정된 상위 개수의 제목·요약을 AI에 전달한다.
5. AI가 숫자 없는 대안 문구 1~3개와 내부 순서를 반환한다.
6. 서버가 대안 수를 빈도 이하로 제한하고 목표 횟수와 100원 단위 절약 예상액을 배분한 뒤 문구의 `{count}`에 횟수를 삽입한다.
7. 사용자가 후보 1개 이상을 선택해 AI 미션으로 확정한다.
8. 검증된 검색 글의 제목·출처·링크를 사용자별 혜택/팁 데이터로 저장한다.

## 예외 흐름

- 네이버 검색 실패는 제한적으로 재시도하고, 계속 실패하면 검색 컨텍스트 없이 5단계부터 계속한다.
- AI 실패 또는 결과 형식 오류는 생성 작업 실패로 반환한다.
- 다른 입력의 생성 작업이 진행 중이면 기존 작업을 잘못 반환하지 않고 충돌을 알린다.
