# 미션 입력 및 생성 플로우

- ID: FLOW-MISSION-001
- 참여자: 사용자, 클라이언트, 미션 서비스
- 시작 조건: 생년월일·거주지역을 포함한 온보딩을 완료한 사용자가 미션 추가를 시작함
- 종료 상태: 선택한 초안이 추천 미션으로 확정되었거나 직접 추가 미션이 생성됨

## 정상 흐름

1. 사용자가 미션 추가 메뉴에서 `추천받기` 또는 `직접입력`을 선택한다.
2. 추천받기를 선택하면 클라이언트가 서버 카탈로그를 조회하고 식비·생활·취미 중 하나와 활성 항목 하나를 순서대로 받는다.
3. 사용자가 기준 빈도와 기준 금액을 입력한다. 클라이언트는 각 답변을 수정할 수 있게 보여 주고, 수정 시 해당 단계 이후 답변을 다시 받는다.
4. 클라이언트가 입력값으로 생성 작업을 요청한다. 요청 성공 시 작업 ID와 만료 시각을 보관하고 작업 ID가 포함된 로딩 화면으로 이동한다.
5. 서버는 선택 항목의 직접 템플릿 3개에 기준 빈도를 적용해 초안을 저장하고 생성 작업을 성공 상태로 만든다.
6. 클라이언트는 서버가 안내한 간격으로 작업 상태를 조회한다. 최소 로딩 표시 시간이 지났고 성공 상태와 초안 조회 가능 상태가 확인되면 결과 화면으로 이동한다.
7. 클라이언트가 초안 3개를 보여 주고 사용자가 1~3개를 선택한다.
8. 서버가 선택된 초안을 추천 미션으로 확정한다. 클라이언트는 미션 목록을 다시 조회할 수 있게 하고 미션 화면으로 이동한다.
9. 직접입력을 선택하면 사용자가 활성 카테고리와 1~30자 문구를 입력한다. 서버가 직접 추가 미션을 만들고 클라이언트는 미션 화면으로 이동한다.

## 예외 흐름

- 카탈로그 조회에 실패하면 항목 단계에서 `다시 불러오기`를 제공한다.
- 생성 작업 시작에 실패하면 입력 화면에 오류를 표시하고 사용자가 다시 요청할 수 있게 한다.
- 같은 입력의 진행 중 작업이 있으면 기존 작업을 계속 사용한다. 다른 입력의 작업이 진행 중이면 충돌을 알리고 두 입력을 섞지 않는다.
- 상태 조회가 한 번 실패했더라도 이전 작업 상태가 있으면 다음 조회를 계속한다. 첫 상태 조회부터 실패하거나 서버가 실패 상태를 반환하면 실패 안내와 미션 화면 이동을 제공한다.
- 앱이 다시 활성화되면 로딩 화면은 즉시 상태를 다시 조회한다.
- 네이티브 앱에 만료되지 않은 보류 작업이 있으면 추천 시작 화면에서 기존 로딩 화면으로 복귀한다. 다른 화면에서 작업이 끝나면 결과 확인 여부를 묻고, 만료 작업은 제거한다.
- 초안 조회에 실패하면 결과 화면에 오류를 표시한다. 확정 실패 시 선택 상태를 유지하고 다시 시도할 수 있게 한다.
- 동기 후보 조회는 생성 작업 없이 후보만 반환하므로 현재 추천 미션 확정 플로우와 섞지 않는다.
