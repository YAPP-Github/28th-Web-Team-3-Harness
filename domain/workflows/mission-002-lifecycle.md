# 미션 수행, 삭제 및 내역 플로우

- ID: FLOW-MISSION-002
- 참여자: 사용자, 클라이언트, 미션 서비스
- 시작 조건: 추천 또는 직접 추가 미션이 존재함
- 종료 상태: 이번 주 완료가 기록되거나 미션이 soft delete되거나 월별 내역을 확인함

## 정상 흐름

1. 클라이언트가 현재 사용자의 삭제되지 않은 미션과 이번 주 완료 기록을 조회한다.
2. 미션 화면은 전체·식비·생활·취미 필터를 제공하고 결과를 진행 중과 완료로 나눠 보여 준다.
3. 상단 요약은 이번 주 완료 수, 전체 수, 진행률, 완료한 추천 미션의 절약 예상액 합과 주간 마감까지 남은 날을 보여 준다.
4. 사용자가 진행 중 미션의 완료 버튼을 누르면 확인 창을 보여 준다. 확인 후 서버는 현재 주 완료 기록을 한 번 저장하고 클라이언트는 목록을 갱신한다.
5. 완료된 미션은 완료 목록으로 이동하고 이번 주 진행률과 절약 요약에 반영된다.
6. 사용자가 진행 중 카드를 펼쳐 삭제를 선택하면 확인 창을 보여 준다. 확인 후 서버가 미션을 soft delete하고 클라이언트는 현재 목록과 진행률에서 제거한다.
7. 사용자가 `내역`으로 이동하면 현재 달의 주차별 완료 수와 전체 수를 조회한다. 미션이 있던 주는 달성률을, 없던 주는 빈 상태를 보여 준다.
8. 사용자는 현재 달보다 미래로 이동할 수 없고 클라이언트에 기록된 최초 미션 생성 월까지만 이전 달로 이동한다.
9. 새 주가 시작되면 클라이언트와 서버가 새 월요일 시작일로 조회하므로 유지 중인 미션이 다시 진행 중으로 보인다.

## 예외 흐름

- 목록 조회에 실패하고 이전 데이터도 없으면 오류 안내를 보여 준다. 이전 데이터가 있으면 기존 목록을 유지한다.
- 완료·삭제 요청 중에는 확인 창을 닫거나 요청을 중복 전송하지 않는다. 실패하면 오류를 보여 주고 창과 대상 미션을 유지한다.
- 같은 주 완료 요청이 반복되면 기존 완료를 사용하고 주간 완료 행을 추가하지 않는다.
- 다른 사용자의 미션, 존재하지 않는 미션, 삭제된 미션은 완료·삭제하지 않는다.
- 완료 취소는 지원하지 않는다.
- 내역 조회 실패 시 선택한 달을 유지하고 오류를 보여 준다.
- 서버는 2026년 8월보다 이전 달과 미래 달을 거절한다. 클라이언트의 최초 생성 월 기록이 없으면 이전 달 이동을 막는다.
- 삭제된 미션의 완료 원본 행은 남지만 현재 주와 삭제 전에 끝나지 않은 주의 내역 집계에서는 제외될 수 있다.
