# 미션 수행 및 주간 반복 플로우

- ID: FLOW-MISSION-002
- 참여자: 사용자, 클라이언트, 미션 서비스
- 시작 조건: AI 또는 직접 추가 미션이 존재함
- 종료 상태: 이번 주 완료가 기록되거나 미션이 soft delete됨

## 정상 흐름

1. 홈은 현재 삭제되지 않은 미션 중 이번 주 미완료 미션만 카테고리 필터와 함께 보여준다.
2. 상세는 같은 미션들의 이번 주 완료·미완료 상태를 평면 목록으로 보여준다.
3. 사용자가 체크하면 `mission_id + week_start_date` 완료 기록을 한 번 생성하고 홈에서 즉시 숨긴다.
4. 진행률은 현재 완료 수를 현재 미션 수로 나누며 주중 추가된 미션도 즉시 포함한다.
5. 다음 월요일 00:00(Asia/Seoul)에는 새로운 주 시작일로 조회하므로 모든 유지 미션이 다시 미완료로 보이고 진행률은 0부터 시작한다.
6. 사용자가 삭제하면 미션을 soft delete해 현재 조회와 진행률에서 제외하고 과거 주간 기록은 유지한다.

## 예외 흐름

- 이미 완료한 미션을 다시 완료해도 주간 기록을 중복 생성하지 않는다.
- 다른 사용자의 미션, 존재하지 않는 미션, 삭제된 미션은 완료·삭제할 수 없다.
- 완료 취소는 지원하지 않으며 정책 변경 시 별도 API로 추가한다.
