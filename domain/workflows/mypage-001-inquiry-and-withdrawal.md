# 마이페이지 문의 및 탈퇴 플로우

- ID: FLOW-MYPAGE-001
- 참여자: 사용자, 클라이언트, 네이티브 앱, 인증 서비스, 외부 문의 채널
- 시작 조건: 인증된 게스트가 마이페이지에 진입함
- 종료 상태: 문의 채널이 열리거나, 탈퇴가 취소되거나, 게스트 계정 삭제 후 온보딩 첫 화면으로 이동하거나, 실패 안내 후 재시도 가능한 상태가 됨

## 정상 흐름

### 문의

1. 사용자가 문의하기를 선택하면 클라이언트가 문의 바텀시트를 연다.
2. 클라이언트는 설정된 주소가 HTTPS 카카오톡 오픈채팅 주소인지 확인한다.
3. 유효한 주소이면 카카오톡 문의 버튼을 제공하고, 없거나 유효하지 않으면 이메일 주소와 이메일 문의 버튼을 제공한다.
4. 사용자가 버튼을 누르면 네이티브 앱에서는 외부 이동 기능으로, 일반 브라우저에서는 브라우저가 지원하는 방식으로 문의 채널을 연다.

### 탈퇴

1. 사용자가 탈퇴하기를 선택하면 클라이언트가 데이터가 모두 사라진다는 확인 화면을 연다.
2. 사용자가 아니요를 선택하면 확인 화면을 닫고 계정과 데이터를 유지한다.
3. 사용자가 탈퇴하기를 확정하면 클라이언트가 중복 제출과 화면 닫기를 막고 인증된 게스트 탈퇴를 요청한다.
4. 인증 서비스는 요청한 게스트의 존재를 확인한다.
5. 인증 서비스는 해당 게스트의 혜택 저장 내역, 미션과 추천 기록, 온보딩 정보, 목표·저축 정보, refresh token과 게스트 계정을 한 트랜잭션에서 삭제한다.
6. 삭제가 성공하면 기존 access token과 refresh token은 더 이상 인증에 사용할 수 없다.
7. 클라이언트는 사용자 데이터 캐시를 비우고, 네이티브 앱이면 기기에 남은 게스트 토큰도 비운다.
8. 클라이언트는 온보딩 첫 화면을 새로 열고 이후 인증 과정에서 새 게스트 계정을 사용한다.

## 예외 흐름

- 문의 채널을 외부에서 열지 못해도 문의 화면은 닫히거나 다른 화면으로 바뀌지 않는다. 이메일 대체 경로에서는 사용자가 직접 옮겨 적을 수 있도록 주소를 화면에 남긴다.
- 탈퇴 요청에 유효한 access token이 없거나 계정이 이미 존재하지 않으면 인증 서비스가 요청을 거절한다.
- 탈퇴 중 계정 삭제가 완료되지 않으면 전체 삭제를 취소해 처리 전 상태를 유지한다.
- 탈퇴 요청이 실패하면 클라이언트는 확인 화면에 실패 안내를 표시하고 버튼을 다시 사용할 수 있게 한다.
- 서버 탈퇴가 성공했지만 네이티브 토큰 정리가 실패하면 클라이언트는 온보딩 첫 화면 이동을 계속한다. 서버에서 기존 토큰이 무효이므로 이전 계정으로 복귀할 수 없다.
