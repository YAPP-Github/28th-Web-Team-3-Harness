# 마이페이지 문의 및 탈퇴 플로우

- ID: FLOW-MYPAGE-001
- 참여자: 사용자, 클라이언트, 계정 서비스, 문의 채널
- 시작 조건: 사용자가 마이페이지에서 문의하기 또는 탈퇴하기를 선택함
- 종료 상태: 문의 채널로 이동했거나, 탈퇴를 취소했거나, 탈퇴 후 새 사용자 시작 화면으로 이동했거나, 실패 안내 후 탈퇴 전 상태를 유지함

## 정상 흐름

### 문의

1. 사용자가 문의하기를 선택하면 클라이언트가 문의 안내를 연다.
2. 클라이언트는 사용 가능한 공식 카카오톡 오픈채팅 채널이 있으면 카카오톡 문의를, 없으면 이메일 문의를 제시한다.
3. 사용자가 문의 버튼을 선택하면 클라이언트가 선택된 외부 문의 채널을 연다.

### 탈퇴

1. 사용자가 탈퇴하기를 선택하면 클라이언트가 탈퇴 확인 창을 연다.
2. 사용자가 취소하면 확인 창을 닫고 탈퇴 요청을 보내지 않는다.
3. 사용자가 탈퇴를 확인하면 계정 서비스에 탈퇴를 요청한다.
4. 요청 처리 중에는 확인 창을 유지하고 중복 탈퇴 요청을 막는다.
5. 탈퇴가 성공하면 계정과 삭제 대상 사용자 데이터를 삭제하고 새 사용자 시작 화면으로 이동한다.

## 예외 흐름

- 공식 카카오톡 오픈채팅 채널이 없거나 사용할 수 없으면 이메일 주소와 이메일 문의 버튼을 제공한다.
- 탈퇴 요청이 실패하면 확인 창을 열어 둔 채 실패 사실을 안내하고 사용자가 다시 시도할 수 있게 한다.
