# 홈 대시보드 조회와 이동 플로우

- ID: FLOW-HOME-001
- 참여자: 온보딩을 완료한 사용자, FE, BE
- 시작 조건: 사용자가 유효한 인증 상태로 홈에 진입한다.
- 종료 상태: 홈의 각 영역이 조회 결과 또는 독립 실패 상태를 표시하고, 사용자가 홈에 머물거나 목표·미션·혜택 후속 화면으로 이동한다.

## 정상 흐름

1. FE는 홈 진입 시 목표 현황, 현재 주에 조회 가능한 전체 미션, 선택된 분류의 진행 중 미션, 혜택 요약을 독립적으로 요청한다. BE는 삭제된 미션과 비활성화된 항목에 속한 추천 미션을 미션 응답에서 제외한다.
2. 응답을 기다리는 동안 각 영역은 자체 로딩 상태를 표시한다.
3. 목표 현황 응답이 오면 FE는 전체 목표·현재 총액과 이번 달 목표·저축액·달성률·남은 날짜를 표시한다.
4. 사용자가 전체 목표 행을 누르면 목표 상세로 이동한다.
5. 사용자가 현재 저축액 입력을 누르면 기존 이번 달 저축액을 채운 입력 화면을 연다.
6. 사용자가 유효한 금액을 저장하면 BE는 이번 달 값을 덮어쓰고 갱신 결과를 반환한다. FE는 목표 현황을 다시 조회한 뒤 입력 화면을 닫는다.
7. 미션 응답이 오면 FE는 조회 가능한 전체 미션으로 이번 주 완료 개수·달성률·절약 예상액 합계를 만들고, 그중 진행 중 미션을 최대 3개씩 표시한다.
8. 사용자가 분류를 바꾸면 FE는 해당 분류의 진행 중 미션을 요청하고 첫 페이지를 표시한다.
9. 사용자가 미션을 펼치면 절약 예상 정보를 표시한다. 완료 버튼을 누르면 확인 화면을 연다.
10. 사용자가 완료를 확정하면 BE는 현재 주 완료를 기록한다. FE는 목록을 갱신해 요약과 진행 중 목록을 최신 상태로 표시한다.
11. 사용자가 이번 주 미션 제목의 이동 버튼을 누르면 미션 전체 화면으로 이동한다.
12. 진행 중 미션이 없으면 FE는 플랫폼별 미션 생성 이력 판정에 따라 이동을 제공한다. 네이티브 브리지가 불리언 `true`를 반환하거나 브라우저 저장 문자열이 정확히 `"true"`이면 직접 입력·추천받기를 함께 제공하고, 그 외에는 추천받기만 제공한다.
13. 혜택 응답이 오면 FE는 최대 5개 카드를 표시한다. 사용자가 카드를 누르면 혜택 목록 화면으로 이동한다.

## 예외 흐름

- 목표 최초 조회가 실패하면 목표 영역에 `목표를 불러오지 못했어요. 잠시 후 다시 시도해 주세요.`를 표시한다. 미션과 혜택 영역은 계속 처리한다.
- 목표 응답이 없어도 미션 영역은 계속 표시한다. 빈 미션 추천 버튼의 목표 금액 부분은 구체적 금액 대신 `목표`로 표시한다.
- 저축액 저장이 실패하면 입력 화면을 닫지 않고 `저장하지 못했어요. 잠시 후 다시 시도해 주세요.`를 표시한다.
- 저축액 저장은 성공했지만 후속 조회가 실패하면 저장 성공을 실패로 바꾸지 않는다. 입력 화면을 닫고 이후 목표 조회에서 복구한다.
- 전체 미션 또는 선택 분류 미션의 최초 조회가 실패하면 미션 영역에 `미션을 불러오지 못했어요. 잠시 후 다시 시도해 주세요.`를 표시한다. 목표와 혜택 영역은 유지한다.
- 분류 전환 재조회 중에는 직전 미션 목록을 유지하고 전환 중 상태로 표시한다.
- 미션 완료가 실패하면 확인 화면을 유지하고 `완료 처리하지 못했어요. 잠시 후 다시 시도해 주세요.`를 표시한다. 사용자는 취소하거나 다시 시도할 수 있다.
- 미션 생성 이력을 확인하지 못하면 생성 이력이 없는 것으로 처리해 추천받기만 제공한다.
- 브라우저에서 이전 저장값이 없을 때 현재 생성 성공 흐름은 서울 기준 날짜를 저장하지만 조회는 문자열이 정확히 `"true"`인지 확인한다. 따라서 새 생성 성공 후에도 추천받기만 표시된다.
- 조회 가능한 미션이 하나도 없으면 이번 주 남은 날짜를 `D-7`로 표시한다.
- 혜택 최초 조회가 실패하면 혜택 영역 제목과 `혜택을 불러오지 못했어요. 잠시 후 다시 시도해 주세요.`를 표시한다. 목표와 미션 영역은 유지한다.
- 이미 표시한 데이터의 재조회가 실패하면 해당 영역은 기존 데이터를 유지한다.
