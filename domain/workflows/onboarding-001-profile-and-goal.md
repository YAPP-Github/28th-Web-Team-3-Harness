# 게스트 프로필 입력 및 목표 확정 플로우

- ID: FLOW-ONBOARDING-001
- 참여자: 사용자, 클라이언트, 게스트 인증 서비스, 온보딩 서비스, 목표 서비스
- 시작 조건: 앱을 실행한 게스트 사용자의 인증 정보가 준비되었거나 재발급을 시도함
- 종료 상태: 목표가 확정되어 온보딩이 완료되고 홈으로 이동했거나, 복구 가능한 오류 상태에서 현재 단계에 머묾

## 정상 흐름

1. 클라이언트는 저장된 갱신 토큰으로 게스트 인증을 갱신한다. 토큰이 없거나 거부되면 기기에 보존된 같은 식별값으로 게스트 인증을 다시 발급한다.
2. 인증 서비스는 같은 식별값을 기존 게스트 사용자와 연결하고 접근 토큰과 일회성 회전 방식의 갱신 토큰을 발급한다.
3. 클라이언트가 현재 사용자의 온보딩 완료 여부를 조회한다. 미완료 사용자는 소개 화면으로, 완료 사용자는 홈으로 이동한다.
4. 사용자가 소개 화면에서 시작하고 생년월일, 거주지역, 월급·월 저축액, 순자산, 목표 기간을 차례로 입력한다.
5. 클라이언트는 각 답변을 부분 저장한다. 저장된 답변은 다음 화면과 재진입 시 복원한다.
6. 사용자가 검토 화면에서 모든 답변을 확인하고 완료를 선택한다.
7. 클라이언트가 목표 미리보기를 조회한다. 공식 화면은 월급이 있는 프로필만 요청하며, 온보딩 서비스는 현재 월 저축액부터 `현재 월 저축액 × 1.5`를 1만원 단위 아래에서 버린 값과 월급 중 작은 값까지의 범위, 권장값, 목표 기간, 순자산을 반환한다.
8. 사용자가 1만원 단위로 월 저축 목표를 조정한다. 클라이언트는 `순자산 + 월 저축 목표 × 목표 기간`을 즉시 보여준다.
9. 사용자가 목표 시작을 선택한다. 목표 서비스는 선택값을 다시 검증하고 온보딩 목표와 서비스 목표를 생성한 뒤 프로필을 완료 상태로 바꾼다.
10. 클라이언트는 사용자와 프로필의 완료 상태를 갱신하고 홈으로 교체 이동한다.

## 예외 흐름

- 게스트 인증의 일시적 서버·네트워크 실패는 저장된 갱신 토큰을 폐기하거나 신규 계정을 만들지 않는다. 이후 인증 요청에서 다시 시도한다.
- 현재 사용자 조회가 실패하면 완료 여부를 추정하지 않고 오류 처리로 넘긴다.
- 질문 저장이 실패하면 오류를 보여주고 같은 단계에서 재시도한다. 중복 제출 중에는 추가 저장을 시작하지 않는다.
- 거주지역이 서버 기본값인 서울이더라도 사용자 확인 기록이 없으면 거주지역 질문으로 돌아간다.
- 검토 화면에서 필수 답변이 빠졌으면 완료를 비활성화한다. 목표 화면에서 누락이 확인되면 검토 화면으로 돌아간다.
- 공식 화면을 거치지 않은 요청의 프로필에 월급이 없으면 서버는 `현재 월 저축액 × 1.5`를 1만원 단위 아래에서 버린 값을 최댓값으로 사용한다.
- 미리보기 조회가 실패하면 결과를 불러오지 못했다는 안내를 보여주고 페이지 재진입을 요청한다.
- 확정값이 현재 저축액보다 작거나 허용 최댓값보다 크면 목표 확정을 거절한다.
- 목표 확정이 일반 오류로 실패하면 현재 목표 선택을 유지하고 재시도한다.
- 목표는 저장됐지만 성공 응답을 받지 못한 재시도가 `ONBOARDING_ALREADY_COMPLETED`로 끝나면 완료로 복구하고 홈으로 이동한다.
- 이전 경로인 목표 선택 화면으로 진입하면 현재 목표 결과 화면으로 이동한다.
