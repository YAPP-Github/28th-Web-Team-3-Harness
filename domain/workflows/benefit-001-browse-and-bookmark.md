# 혜택 탐색 및 저장 플로우

- ID: FLOW-BENEFIT-001
- 참여자: 사용자, 클라이언트, 혜택 서비스
- 시작 조건: 게스트 인증이 완료됨
- 종료 상태: 사용자가 정책 혜택·절약 팁을 확인하거나 외부 원문으로 이동하고, 마지막 저장 의도가 반영됨

## 정상 흐름

1. 사용자가 혜택 화면에 진입하면 `정책 혜택` 탭과 `전체` 필터를 선택해 첫 정책 페이지를 조회한다.
2. 혜택 서비스는 온보딩 프로필에서 확인되는 만 나이·거주지역을 적용하고 조회수 순 정책과 게스트별 저장 여부를 반환한다.
3. 사용자가 `금융`, `주거`, `복지`, `교육` 필터를 선택하면 해당 정규화 분류의 첫 페이지로 전환하고 공유 가능한 필터 주소를 유지한다.
4. 사용자가 목록 끝에 가까워지면 다음 페이지를 이어 붙인다. 요청한 페이지보다 적은 항목을 받으면 마지막 페이지로 판단한다.
5. 사용자가 정책 설명 화살표를 누르면 외부 이동 없이 설명만 펼치거나 접는다.
6. 사용자가 정책 카드를 선택하면 상세의 신청 링크를 조회하고, 링크가 있으면 외부 신청 페이지를 연다.
7. 사용자가 `절약 팁` 탭을 선택하면 안내 문구를 절약 팁 기준으로 바꾸고 `전체` 또는 `식비`, `생활`, `취미` 필터의 팁을 조회한다.
8. 사용자가 원문 링크가 있는 절약 팁 카드를 선택하면 외부 원문을 연다. 링크가 없으면 카드 내용만 제공한다.
9. 사용자가 별을 누르면 화면의 저장 상태를 즉시 바꾼다. 정책 혜택의 연속 입력은 짧게 모아 콘텐츠별로 순서대로 반영하며 화면이 유지되는 동안 마지막 입력과 서버 상태가 같아질 때 종료한다. 아직 요청을 시작하지 않은 변경은 화면을 떠날 때 전송한다.
10. 사용자가 `저장됨`을 선택하면 별도 화면에서 `정책 혜택`을 먼저 보여 준다. `절약 팁` 탭으로 바꾸면 전체 팁 중 현재 게스트가 저장한 팁만 보여 준다.
11. 저장됨 화면에서 정책 혜택의 별을 누르면 `저장을 취소할까요?` 확인을 보여 준다. 사용자가 `취소`를 선택하면 저장을 해제하고 목록에서 제거하며, `아니요`를 선택하면 유지한다.
12. 저장됨 화면에서 절약 팁의 별을 누르면 확인 없이 저장을 해제하고 목록에서 제거한다.
13. 저장됨 화면의 뒤로가기는 앱 내 이전 화면이 있으면 그 화면으로, 없으면 혜택 화면으로 이동한다.

## 예외 흐름

- 알 수 없거나 여러 개의 정책 분류 값으로 진입하면 `전체`로 조회한다. 이전 `저장` 필터 주소로 진입하면 별도 저장됨 화면으로 이동한다.
- 정책 첫 페이지 조회가 실패하면 오류를 알리고 `다시 시도` 시 첫 페이지를 다시 조회한다.
- 정책 다음 페이지 조회가 실패하면 기존 목록을 유지하고 `다시 시도` 시 실패한 다음 페이지를 다시 조회한다.
- 정책 상세 조회가 실패하면 카드에 오류를 표시하고 외부 페이지를 열지 않는다. 신청 링크가 없으면 신청 페이지가 등록되지 않았음을 표시한다.
- 절약 팁 조회가 실패하면 오류를 알리고 `다시 시도` 시 같은 분류를 다시 조회한다.
- 저장 변경이 실패하면 낙관적으로 바꾼 상태를 서버에서 마지막으로 확인된 상태로 되돌리고 오류를 표시한다. 자동으로 같은 실패를 반복하지 않는다.
- 정책 혜택 저장 요청이 이미 진행 중인 상태에서 사용자가 다시 별을 누르고 즉시 화면을 떠나면 나중 입력이 전송되지 않을 수 있다. 다음 진입의 서버 조회 결과를 기준으로 표시한다.
- 저장한 정책 목록 조회가 실패하면 오류와 재시도를 제공한다. 목록이 비면 관심 있는 혜택의 별을 눌러 저장하라고 안내한다.
- 저장한 절약 팁이 없으면 관심 있는 팁의 별을 눌러 저장하라고 안내한다.
