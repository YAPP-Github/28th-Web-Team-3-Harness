# 혜택 탐색 및 저장 플로우

- ID: FLOW-BENEFIT-001
- 참여자: 사용자, 클라이언트, 혜택 서비스, 공식 신청 페이지
- 시작 조건: 사용자가 혜택 화면에 진입하거나 혜택 필터·카드·저장 상태를 선택함
- 종료 상태: 혜택 목록이 표시되었거나, 저장 상태가 확정되었거나, 공식 신청 페이지가 열렸거나, 사용자에게 실패 사유가 안내됨

## 정상 흐름

1. 사용자가 혜택 화면에 진입하면 클라이언트는 유효한 기존 필터 선택을 적용하고, 별도 선택이 없으면 `전체`를 적용해 첫 혜택 페이지를 조회한다.
2. 혜택 서비스가 결과를 반환하면 클라이언트는 제목과 제공된 설명·혜택 표시 분류, 현재 저장 상태로 카드를 보여 준다. 혜택 표시 분류는 제공된 문자열을 그대로 사용하고 혜택 필터 분류로 추론하거나 변환하지 않는다.
3. 사용자가 `금융`, `주거`, `복지`, `교육` 중 하나를 선택하면 클라이언트는 해당 혜택 필터 분류의 첫 페이지를 새로 조회한다.
4. 사용자가 `저장`을 선택하면 클라이언트는 저장한 콘텐츠 중 혜택만 조회해 보여 준다.
5. `전체` 또는 혜택 필터 분류 목록에 다음 페이지가 있고 사용자가 목록 끝에 가까워지면 클라이언트는 다음 페이지를 조회해 기존 목록 뒤에 붙인다. 다음 페이지가 없으면 추가 조회를 끝낸다.
6. 사용자가 혜택의 저장 상태를 바꾸면 클라이언트는 마지막 선택 상태를 즉시 보여 주고 혜택 서비스에 반영한다. 반영 중 같은 혜택을 다시 바꾸면 앞선 처리 뒤에 최종 선택 상태를 반영한다.
7. 사용자가 혜택 카드를 선택하면 클라이언트는 해당 혜택의 최신 상세 정보를 조회한다.
8. 상세 정보에 공식 신청 페이지가 있으면 클라이언트는 해당 외부 페이지를 연다.

## 예외 흐름

- 첫 조회, 필터 전환 또는 추가 조회에 실패하면 혜택 목록을 불러오지 못했음을 안내한다.
- 선택한 혜택 필터 분류에 결과가 없으면 `해당하는 혜택이 없어요.`를 보여 준다.
- `저장` 목록에 결과가 없으면 `저장한 혜택이 없어요.`와 혜택의 별을 눌러 저장하라는 안내를 보여 준다.
- 저장 상태 변경에 실패하면 화면을 변경 전 상태로 되돌리고 `저장 상태를 바꾸지 못했어요. 잠시 후 다시 시도해 주세요.`를 보여 준다.
- 상세 정보에 공식 신청 페이지가 없으면 외부 페이지를 열지 않고 `신청 페이지가 등록되지 않은 혜택이에요.`를 보여 준다.
- 상세 정보 조회에 실패하면 외부 페이지를 열지 않고 `혜택 정보를 불러오지 못했어요. 잠시 후 다시 시도해 주세요.`를 보여 준다.
