# 온보딩 완료 후 내 정보 수정 플로우

- ID: FLOW-ONBOARDING-002
- 참여자: 사용자, 클라이언트, 온보딩 서비스, 목표 서비스
- 시작 조건: 인증된 사용자가 내 정보 수정 화면에 진입함
- 종료 상태: 프로필과 필요한 목표 기간 동기화가 끝나 이전 화면으로 이동했거나, 복구 가능한 오류 상태에서 수정 화면에 머묾

## 정상 흐름

1. 클라이언트가 현재 온보딩 프로필을 조회해 생년월일, 월급, 월 저축액, 순자산, 목표 기간을 수정 폼에 채운다. 거주지역은 현재 수정 대상이 아니다.
2. 사용자가 값을 바꾼다. 생년월일은 오늘 이전 날짜여야 하고 월급·월 저축액·순자산은 필수다. 월 저축액은 월급을 초과할 수 없다.
3. 사용자가 저장하면 클라이언트는 프로필 전체 수정 요청을 보낸다. 부분 저장 계약은 사용하지 않는다.
4. 온보딩 서비스가 프로필을 갱신한다. 기존 서비스 목표가 있으면 순자산을 기준 금액으로, 월 저축액을 월 저축 목표로, 프로필 목표 기간을 목표 기간으로 반영해 목표 금액을 다시 계산한다.
5. 온보딩 완료 상태이고 사용자가 목표 기간을 실제로 바꿨으면 클라이언트가 목표 기간 수정 요청을 추가로 보낸다. 현재 FE는 프로필 수정으로 이미 수행된 서버 재계산과 별도로 이 요청을 실행한다.
6. 클라이언트는 목표 상태와 리포트 데이터를 무효화하고 이전 화면으로 이동한다. 목표 화면에서 진입한 경우에는 목표 화면으로 교체 이동한다.

## 예외 흐름

- 프로필 조회에 실패하면 임의의 초기값으로 저장하지 않고 조회 오류를 처리한다.
- 프로필 수정에 실패하면 수정 화면에 머물고 프로필 전체 수정을 다시 시도한다.
- 프로필 수정은 성공했지만 목표 기간 수정이 실패하면 프로필 수정을 반복하지 않는다. 수정 화면에 머물며 목표 기간 동기화만 다시 시도한다.
- 저장 중에는 같은 수정 요청을 중복 전송하지 않는다.
- 온보딩이 아직 `IN_PROGRESS`이거나 목표 기간이 바뀌지 않았으면 별도 목표 기간 수정 요청을 보내지 않는다.
