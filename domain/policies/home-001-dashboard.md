# 홈 대시보드 정책

- ID: POLICY-HOME-001
- 상태: active
- 적용 범위: 온보딩을 완료한 사용자의 홈 목표 현황, 이번 주 미션 요약, 눈여겨볼 만한 혜택/팁 표시와 홈에서 시작하는 이동·입력·완료 동작

## 규칙

### 화면 구성과 독립 조회

- 홈은 목표 현황, 이번 주 미션, 눈여겨볼 만한 혜택/팁 순서로 구성한다.
- 각 영역은 서로 독립적으로 조회하고 로딩 또는 실패 상태를 표시한다. 한 영역의 실패 때문에 다른 영역의 조회 결과를 숨기지 않는다.
- 최초 조회 중에는 영역별 로딩 상태를 표시한다. 이미 표시한 데이터가 있는 재조회 실패에서는 기존 데이터를 유지한다.

### 목표 현황

- 전체 목표에는 목표 금액과 현재까지 모은 총액을 만원 단위로 표시하고, 해당 행을 누르면 목표 상세로 이동한다.
- 현재까지 모은 총액은 목표 확정 시점의 순자산과 월별 저축액 합계다. 순자산을 다시 더하지 않는다.
- 이번 달 목표 현황에는 이번 달 목표액, 입력된 저축액, 달성률, 월말까지 남은 날짜를 표시한다.
- 이번 달 달성률은 실제 금액 비율을 반올림하고 표시 최댓값을 100%로 제한한다. 목표를 초과해도 실제 금액은 그대로 유지한다.
- 사용자는 홈에서 현재 저축액 입력을 열 수 있다. 입력값은 이번 달 저축액을 더하는 값이 아니라 덮어쓰는 값이며, 0 이상 100,000 이하 정수 만원이어야 한다.
- 저축액 저장 성공 후 목표 현황을 다시 조회하고 입력 화면을 닫는다. 저장 실패 시 입력 화면을 유지하고 재시도 안내를 표시한다.

### 이번 주 미션

- 요약은 현재 주의 삭제되지 않은 전체 미션을 기준으로 남은 날짜, 완료 개수, 전체 개수, 달성률, 완료 미션의 절약 예상액 합계를 표시한다.
- 홈에 표시하는 미션 목록은 아직 완료하지 않은 미션만 대상으로 한다. `전체`, `식비`, `생활`, `취미` 중 하나로 필터링하며 필터 전환 시 첫 페이지로 돌아간다.
- 한 페이지에는 최대 3개를 표시한다. 3개를 초과하면 이전·다음 페이지로 이동한다.
- 미션을 펼치면 추천 미션에는 절약 예상액을 표시한다. 직접 추가 미션에는 절약 예상액이 없다는 대체 설명을 표시한다.
- 미션 완료는 확인을 받은 뒤 처리한다. 성공하면 미션 목록과 요약을 갱신하고, 실패하면 확인 화면을 유지한 채 재시도 안내를 표시한다.
- 이번 주 미션 제목의 이동 동작은 미션 전체 화면으로 연결한다.
- 완료하지 않은 미션이 없으면 미션 추가 안내를 표시한다. 미션 생성 이력이 없으면 추천받기만, 생성 이력이 있으면 직접 입력과 추천받기를 함께 제공한다. 생성 이력 확인 중에는 행동 버튼 자리를 로딩 상태로 유지한다.

### 눈여겨볼 만한 혜택/팁

- 현재 구현은 절약 팁이 아니라 사용자에게 노출 가능한 청년정책 혜택 첫 페이지를 최대 5개 표시한다.
- 혜택은 온보딩 생년월일과 거주지역이 있으면 각각 연령과 지역 조건을 적용하고, 조회수 내림차순으로 정렬한다. 입력하지 않은 조건은 필터링에 사용하지 않는다.
- 카드 분류는 세부 분류, 대분류, `정부 정책` 순서로 사용할 수 있는 첫 값을 표시한다.
- 설명이 없으면 상세 내용을 확인하라는 대체 문구를 표시한다.
- 어떤 카드를 눌러도 해당 카드 상세로 바로 이동하지 않고 혜택 목록 화면으로 이동한다.
- 조회 결과가 비어 있으면 영역 제목은 유지하고 카드를 표시하지 않는다.

## 불변조건

- 목표 금액과 저축액은 만원 단위, 미션 절약 예상액은 원 단위다.
- 미션 요약은 현재 주 전체 미션을 기준으로 하고, 카드 목록은 아직 완료하지 않은 미션만 표시한다.
- 직접 추가 미션의 절약 예상액 부재를 0원 절약으로 카드에 표시하지 않는다. 다만 요약 합계에서는 0원으로 계산한다.
- 홈은 미션 생성 규칙, 혜택 저장 규칙, 혜택 신청 규칙을 정의하지 않는다. 각 모듈 화면으로 이동하는 진입점만 제공한다.
- 사용자별 데이터는 현재 인증된 사용자 범위에서만 조회·변경한다.

## 예외

- 목표가 없으면 서버는 목표 조회를 거부한다. 홈은 이를 별도 온보딩 안내로 구분하지 않고 목표 조회 실패 안내로 표시한다.
- 기존 교통 미션은 `전체` 목록과 요약에 포함될 수 있지만 홈에는 `교통` 필터가 없다.
- 홈 미션 달성률은 조회한 미션 목록으로 반올림해 계산한다. 서버의 별도 진행률 조회는 정수 나눗셈을 사용하므로 일부 비율에서 1%포인트 차이가 날 수 있으며, 현재 홈은 별도 진행률 조회를 사용하지 않는다.
- `눈여겨볼 만한 혜택/팁`이라는 화면 명칭과 달리 현재 홈은 청년정책 혜택만 조회한다. 절약 팁 포함 여부는 확정하지 않는다.
