# 혜택 탐색 및 저장 정책

- ID: POLICY-BENEFIT-001
- 상태: active
- 적용 범위: 혜택 목록 조회, 분류 선택, 혜택 저장·해제와 공식 신청 페이지 이동

## 규칙

- 혜택 목록은 `전체`, `저장`, `금융`, `주거`, `복지`, `교육` 필터를 제공하며 사용자는 한 번에 하나만 선택한다.
- `전체`는 분류 제한 없이 혜택을 조회하고, `금융`, `주거`, `복지`, `교육`은 선택한 혜택 필터 분류에 해당하는 혜택만 조회한다.
- `저장`은 사용자가 저장한 콘텐츠 중 혜택만 보여 주며, 다른 종류의 저장 콘텐츠는 포함하지 않는다.
- 혜택 목록은 페이지 단위로 조회한다. `전체`와 혜택 필터 분류 목록에 다음 페이지가 있으면 현재 목록 뒤에 이어서 보여 준다.
- 목록 응답이 전체 개수를 제공하지 않으므로 화면에 고정된 혜택 개수나 전체 개수를 표시하지 않는다.
- 혜택 카드는 제목, 제공된 설명, 제공된 혜택 표시 분류와 현재 저장 상태를 보여 준다. 설명이나 혜택 표시 분류가 없으면 해당 정보를 임의로 만들지 않는다.
- 혜택 표시 분류는 혜택 서비스가 제공한 문자열을 그대로 사용하며, 혜택 필터 분류로 추론하거나 변환하지 않는다.
- 사용자가 저장 또는 저장 해제를 선택하면 화면은 요청 결과를 기다리지 않고 마지막 선택 상태를 먼저 반영한다. 같은 혜택의 상태를 연속해서 바꾸면 최종 선택 상태가 저장 결과가 되어야 한다.
- 혜택 카드를 선택하면 해당 혜택의 최신 상세 정보에서 공식 신청 페이지를 확인한 뒤 외부 페이지로 이동한다.
- 혜택 정보는 변동될 수 있으므로 사용자가 공식 페이지를 기준으로 확인해야 한다는 안내를 항상 제공한다.

## 불변조건

- 혜택 필터는 동시에 하나만 활성 상태다.
- 저장 상태는 `전체`, 혜택 필터 분류, `저장` 목록에서 같은 혜택에 대해 일관되어야 한다.
- `저장` 목록에는 저장 상태인 혜택만 남아야 한다.
- 혜택 개수, 카드 내용과 신청 페이지 주소를 화면 예시 값으로 고정하지 않는다.
- 공식 신청 페이지가 확인된 경우에만 외부 페이지로 이동한다.

## 예외

- 혜택 목록을 불러오지 못하면 목록을 대신해 재시도를 안내한다.
- 선택한 혜택 필터 분류에 결과가 없으면 해당하는 혜택이 없음을 안내한다.
- 저장한 혜택이 없으면 관심 있는 혜택을 저장하는 방법을 안내한다.
- 저장 상태 변경에 실패하면 변경 전 상태로 되돌리고 재시도를 안내한다.
- 공식 신청 페이지가 등록되지 않은 혜택은 외부 페이지를 열지 않고 등록되지 않았음을 안내한다.
- 혜택 상세 정보를 불러오지 못하면 외부 페이지를 열지 않고 재시도를 안내한다.
