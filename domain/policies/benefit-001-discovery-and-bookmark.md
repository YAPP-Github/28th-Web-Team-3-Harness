# 혜택 탐색 및 저장 정책

- ID: POLICY-BENEFIT-001
- 상태: active
- 적용 범위: 인증된 게스트의 정책 혜택·절약 팁 조회, 분류, 외부 이동, 저장 및 저장 취소

## 규칙

- 혜택 화면은 `정책 혜택`과 `절약 팁`을 분리하며 첫 진입 시 `정책 혜택`을 선택한다.
- 정책 혜택은 온보딩 프로필의 생년월일과 거주지역이 있으면 각각 현재 만 나이와 해당 지역을 기준으로 노출한다. 어느 값이 없으면 해당 조건으로 제한하지 않는다.
- 외부 정책을 가져올 때 `금융`, `주거`, `복지`, `교육` 중 하나로 정규화할 수 있는 정책만 저장 대상으로 삼는다. 이 시점에 마감 또는 사업 종료가 확인된 정책은 건너뛰고 종료일을 알 수 없는 정책은 포함한다.
- 외부 정책의 중분류는 다음 표로 노출 분류를 결정한다.

  | 외부 중분류 | 노출 분류 |
  | --- | --- |
  | 주택 및 거주지, 전월세 및 주거급여 지원, 기숙사 | 주거 |
  | 취약계층 및 금융지원, 재직자 | 금융 |
  | 교육비지원 | 교육 |
  | 건강, 문화활동 및 생활지원, 문화활동 | 복지 |

- 외부 중분류가 `취업`이면 정책명에 `자격증`이 포함된 경우에만 `교육`으로 분류한다.
- 외부 중분류가 쉼표로 여러 개 전달되면 공백과 중복을 제거해 모두 판정하고, 여러 노출 분류에 해당하면 `주거 > 금융 > 교육 > 복지` 순으로 대표 분류 하나를 정한다.
- 정책 혜택 필터는 `전체`, `금융`, `주거`, `복지`, `교육` 중 하나만 선택한다. 알 수 없거나 여러 개가 전달된 필터 값은 `전체`로 취급한다.
- 정책 혜택은 조회수 내림차순, 동률이면 최근 등록 순으로 페이지 조회한다. 응답에 전체 개수가 없으므로 화면은 총개수를 확정해 표시하지 않고 목록 끝에 가까워지면 다음 페이지를 조회한다.
- 정책 혜택 카드는 정규화된 분류, 제목, 설명, 저장 여부를 표시한다. 분류나 설명이 없으면 해당 요소를 표시하지 않으며 설명은 사용자가 펼치거나 접을 수 있다.
- 정책 혜택 카드를 선택하면 상세에서 신청 링크를 확인한 뒤 외부 페이지로 이동한다. 신청 링크가 없으면 등록되지 않았음을 알리고, 상세 조회가 실패하면 재시도 가능한 오류로 알린다.
- 절약 팁 필터는 `전체`, `식비`, `생활`, `취미` 중 하나만 선택한다. 카드는 세부 분류, 제목, 설명, 저장 여부를 표시하며 원문 링크가 있을 때만 외부 원문으로 이동할 수 있다.
- 저장은 게스트와 콘텐츠 유형(`정책 혜택` 또는 `절약 팁`) 및 콘텐츠 ID의 조합으로 구분한다. 같은 콘텐츠를 다시 저장해도 저장 항목은 하나이며, 저장되지 않은 콘텐츠의 저장 취소도 성공으로 취급한다.
- 저장 상태는 목록과 카드에 현재 게스트 기준으로 표시한다. 정책 혜택 화면이 유지되는 동안 연속 입력이 발생하면 마지막 입력 상태를 순서대로 반영하며 실패하면 서버에서 마지막으로 확인된 상태로 되돌리고 오류를 알린다. 절약 팁은 한 변경이 처리되는 동안 같은 항목의 추가 입력을 받지 않는다.
- `저장됨`은 혜택 화면과 분리된 화면이며 `정책 혜택`과 `절약 팁`을 각각 볼 수 있다. 저장한 정책 혜택은 최신 저장 순으로, 저장한 절약 팁은 전체 절약 팁 목록 순서로 표시한다.
- 저장됨 화면에서 정책 혜택의 저장을 취소할 때는 확인을 받는다. 절약 팁은 별을 누르면 별도 확인 없이 저장 상태를 변경한다.

## 불변조건

- 저장 여부는 게스트별로 격리하며 다른 게스트의 저장 상태에 영향을 주지 않는다.
- 같은 숫자 ID라도 정책 혜택과 절약 팁은 다른 콘텐츠로 취급한다.
- 정책 혜택 카드의 표시 분류와 필터 기준은 정규화된 4분류를 사용한다.
- 정책 혜택 화면이 유지되는 동안 빠른 연속 저장 입력은 마지막 입력 상태로 수렴해야 한다.
- 성공한 정책 혜택 저장 취소로 카드가 제거된 뒤에는 저장 취소 전이나 처리 중에 시작한 저장 목록 조회가 늦게 완료되어도 해당 카드가 다시 나타나서는 안 된다.
- 외부 이동 대상 URL이 없거나 상세 조회가 실패한 경우 빈 페이지를 열지 않는다.

## 예외

- 인증 정보가 없으면 정책 혜택, 절약 팁, 저장 목록을 조회하거나 저장 상태를 변경할 수 없다.
- 정책 혜택 첫 페이지 조회가 실패하면 오류와 `다시 시도`를 제공한다. 다음 페이지 조회만 실패하면 이미 받은 목록은 유지하고 다음 페이지 재시도를 제공한다.
- 정책 혜택 목록이 비면 조건에 맞는 혜택이 없음을 알린다. 저장 목록이 비면 저장 방법을 함께 안내한다.
- 절약 팁 조회가 실패하면 오류와 `다시 시도`를 제공한다. 저장된 절약 팁이 없으면 저장 방법을 안내한다.
- 존재하지 않는 콘텐츠 저장은 거절한다. 삭제된 콘텐츠의 과거 저장 행은 저장 목록에서 노출하지 않는다.
- 저장 목록의 정책 분류 계약 차이는 [2026-08-25 혜택 main 기준](../../decisions/2026-08-25-benefit-main-baseline.md)에 따른다.
- 일반 동기화는 이전에 저장된 정책을 삭제하지 않으므로, 저장 후 마감된 정책이 목록에 남을 수 있다. 현재 시스템은 목록에 남은 정책의 최신 마감·신청 가능 여부를 보장하거나 별도 확인 경로를 안내하지 않는다.
- 정책 혜택 저장 요청이 진행 중일 때 다시 상태를 바꾸고 즉시 화면을 떠나면 마지막 변경이 전송되지 않을 수 있다. 운영 개선 전까지 이 동작을 마지막 의도 보장으로 간주하지 않는다.
