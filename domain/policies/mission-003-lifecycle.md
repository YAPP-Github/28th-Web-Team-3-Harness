# 미션 생명주기 정책

- ID: POLICY-MISSION-003
- 상태: active
- 적용 범위: AI·직접 추가 미션의 조회, 완료, 삭제, 주간 진행률

## 규칙

- AI 미션과 직접 추가 미션은 사용자가 삭제할 때까지 주마다 반복된다.
- 완료는 체크 토글 한 번으로 처리하며 실제 횟수·실제 금액을 받지 않는다. 완료 취소 API는 제공하지 않는다.
- 완료 기록은 `mission_id + week_start_date`별 별도 기록이며, 월요일 00:00(Asia/Seoul)에 새 주가 되면 새 주의 완료 수와 진행률은 0부터 계산한다.
- 진행률은 `이번 주 완료된 현재 미션 수 / 현재 삭제되지 않은 전체 미션 수 × 100`이다. 주중 추가 미션도 즉시 분모에 포함하고 AI·직접 추가를 동일 집계한다.
- 홈은 미완료만 보여주며 전체·식사·생활·취미 필터를 제공한다. 상세는 완료와 미완료를 평면 목록으로 보여준다.
- 사용자가 삭제하면 soft delete하고 현재 조회·진행률에서는 제외하되 과거 주간 완료 이력은 보존한다.
- 직접 추가는 카테고리와 최대 30자 문구만 받으며 목표 횟수와 절약액을 별도 관리하지 않는다.

## 불변조건

- 한 주의 완료 기록은 취소하거나 중복 생성하지 않는다.
- AI 카드만 항목 태그와 접기/펼치기 절약 문구를 제공한다. 직접 추가 카드는 카테고리·직접 추가·연필 아이콘으로 구분하며 펼치기가 없다.
- 교통 카테고리의 기존 미션과 연결된 주간 기록은 전환 마이그레이션에서 hard delete해 집계에 남기지 않는다.

## 예외

- 존재하지 않거나 다른 사용자의 미션, soft delete된 미션을 완료·삭제하려 하면 거절한다.
- 인라인 목표 횟수 조정은 미확정 아젠다이며 현재 구현하지 않는다. 채택 시 최소 1회·최대 평소 빈도와 절약액 실시간 재계산을 별도 반영한다.
