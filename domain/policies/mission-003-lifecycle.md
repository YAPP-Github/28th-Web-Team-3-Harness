# 미션 생명주기 및 기록 정책

- ID: POLICY-MISSION-003
- 상태: active
- 적용 범위: 추천·직접 추가 미션의 조회, 완료, 삭제, 주간 진행률과 월별 내역

## 규칙

- 추천 미션과 직접 추가 미션은 사용자가 삭제할 때까지 주마다 반복된다.
- 직접 추가 미션은 활성 카테고리와 공백 제거 후 1~30자인 문구로 만든다. 목표 횟수와 절약 예상액은 없다.
- 미션 화면은 이번 주 상태를 진행 중과 완료로 나눠 보여 주며 전체·식비·생활·취미 필터를 제공한다.
- 완료는 확인 후 한 번 기록하며 실제 횟수·실제 금액을 받지 않는다. 완료 취소는 제공하지 않는다.
- 완료 기록은 미션 출처·미션 ID·서울 시간 기준 월요일 시작일 조합으로 주마다 한 건이다. 새 주 조회는 새 시작일을 사용하므로 유지 중인 미션이 다시 진행 중으로 보인다.
- 이번 주 진행률은 현재 삭제되지 않은 미션 중 완료한 수와 전체 수의 비율이다. 주중 추가 미션은 즉시 전체 수에 포함하고 추천·직접 추가 미션을 함께 집계한다.
- 미션 화면의 절약 합계는 이번 주 완료한 추천 미션의 절약 예상액 합이다. 직접 추가 미션은 0원으로 계산한다.
- 진행 중 카드에서 삭제를 요청하면 미션을 soft delete해 현재 목록과 진행률에서 제외한다. 주간 완료 원본 행은 삭제하지 않는다.
- 월별 내역은 주차별 완료 수·전체 수·달성률을 보여 준다. 미션이 없던 주는 0% 달성이 아닌 `생성된 미션이 없음`으로 표시한다.
- 서버 내역은 2026년 8월부터 현재 달까지만 조회할 수 있고 2026년 8월 17일 전 주차는 0/0으로 제공한다.

## 불변조건

- 같은 미션의 같은 주 완료 기록을 중복 생성하지 않는다.
- 존재하지 않거나 다른 사용자의 미션, soft delete된 미션은 완료·삭제할 수 없다.
- 현재 목록과 진행률은 비활성 항목의 기존 추천 미션을 제외한다.
- 과거 주 내역의 전체 수는 해당 주 종료 시점까지 유지된 미션을 기준으로 한다. 현재 주는 현재 삭제되지 않은 미션만 센다.
- 미래 달과 지원 시작 달 이전 내역은 조회할 수 없다.

## 예외

- 완료·삭제 처리 중에는 결과가 확정되기 전까지 확인 창을 닫거나 같은 요청을 다시 보내지 않는다. 실패하면 현재 화면과 선택을 유지하고 재시도할 수 있다.
- 완료된 카드는 현재 클라이언트에서 삭제 버튼을 노출하지 않지만 서버 삭제 계약은 이번 주 완료 여부와 무관하게 동작한다.
- 주간 완료 행은 보존되어도 삭제 시점에 따라 월별 내역 집계에서 제외될 수 있다.
- 미션 화면과 서버가 진행률 소수점을 처리하는 방식이 다르므로 [진행률 반올림 불일치](../exceptions.md#미션-진행률-반올림-불일치)를 따른다.
