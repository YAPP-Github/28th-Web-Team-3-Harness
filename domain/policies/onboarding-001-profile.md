# 온보딩 프로필 입력 정책

- ID: POLICY-ONBOARDING-001
- 상태: active
- 적용 범위: 게스트 사용자의 최초 온보딩 진입, 프로필 질문 입력·부분 저장·검토·재진입

## 규칙

- 온보딩을 완료하지 않은 게스트 사용자가 일반 서비스 화면에 진입하면 온보딩 소개 화면으로 이동한다. 소개 화면에서 시작하면 프로필 질문을 진행한다.
- 질문 순서는 생년월일, 거주지역, 월급·월 저축액, 순자산, 목표 기간이다. 마지막에 저장된 답변 전체를 검토한다.
- 각 질문은 다음 단계로 이동하기 전에 해당 답변만 부분 저장한다. 저장에 성공한 경우에만 다음 단계로 이동하며, 재진입하면 이미 저장된 답변을 복원한다.
- 생년월일은 실제 존재하는 오늘 이전 날짜여야 한다.
- 거주지역은 서울, 경기, 인천, 부산, 대구, 대전, 세종, 울산, 충남, 충북, 경남, 경북, 전남, 전북, 강원, 제주 중 하나다.
- 서버가 새 프로필의 거주지역을 서울로 채우더라도 사용자가 직접 확인하기 전에는 답변으로 간주하지 않는다.
- 공식 화면에서 월급과 월 저축액은 각각 1~650만원을 입력한다. 월 저축액은 월급을 초과할 수 없다.
- 순자산은 0~10,000만원이다. 0원도 사용자가 명시적으로 선택한 유효한 답변이다.
- 공식 화면의 목표 기간은 6개월 단위로 6~36개월 중에서 선택한다.
- 검토 완료 버튼은 생년월일, 명시적으로 확인한 거주지역, 월급, 월 저축액, 순자산, 목표 기간이 모두 있을 때만 활성화한다.
- 온보딩 목표를 확정한 사용자가 온보딩 경로에 다시 진입하면 홈으로 이동한다.

## 불변조건

- 게스트 사용자별 온보딩 프로필은 하나다.
- 프로필 질문을 일부 저장한 것만으로 온보딩이 완료되지 않는다. 목표 확정 전 상태는 `IN_PROGRESS`다.
- 목표를 확정한 뒤 프로필 상태는 `COMPLETED`다. 최초 온보딩용 부분 저장은 완료된 프로필을 덮어쓰지 않는다.
- 금액 단위는 만원, 목표 기간 단위는 개월이다.
- 프로필이 아직 저장되지 않았어도 조회 결과는 빈 `IN_PROGRESS` 프로필로 취급한다.

## 예외

- 현재 사용자 조회에 실패하면 임의로 완료 여부를 판단하지 않고 오류 처리로 넘긴다.
- 질문 답변 저장에 실패하면 현재 단계에 머물고 다시 저장할 수 있게 한다.
- 서울 확인 기록을 사용할 수 없으면 현재 진행은 계속할 수 있지만 재진입 시 거주지역을 다시 확인한다.
- 서버는 월급·월 저축액 0과 3~36개월의 모든 정수를 허용하지만 공식 화면의 선택 범위는 더 좁다. 이 차이는 [온보딩 main 구현 기준 결정](../../decisions/2026-08-25-onboarding-main-baseline.md)에 기록한다.
