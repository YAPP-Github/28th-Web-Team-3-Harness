# 온보딩 목표 설정 정책

- ID: POLICY-ONBOARDING-002
- 상태: active
- 적용 범위: 프로필 검토 완료 후 월 저축 목표 미리보기, 조정, 확정과 온보딩 완료, 완료 이후 내 정보 수정에 따른 목표 재계산

## 규칙

- 공식 화면은 프로필의 모든 질문값과 명시적으로 확인한 거주지역이 있어야 목표 미리보기를 요청한다.
- 월 저축 목표의 최솟값은 현재 월 저축액이다. 최댓값은 현재 월 저축액의 150%와 월급 중 작은 값이다. 비율 계산에서 1만원 미만 소수는 버린다.
- 공식 화면은 월급이 없는 프로필로 목표 미리보기를 요청하지 않는다. 서버가 월급 없는 프로필의 요청을 직접 받으면 현재 월 저축액의 150%를 소수 버림한 값을 최댓값으로 사용한다.
- 기본 월 저축 목표는 서버 설정의 권장 상향률을 같은 소수 버림 방식으로 적용하되 최댓값을 넘지 않도록 제한한다.
- 사용자는 최솟값부터 최댓값까지 1만원 단위로 월 저축 목표를 조정할 수 있다.
- 목표 예상 금액은 `현재 순자산 + 월 저축 목표 × 목표 기간`으로 계산한다.
- 화면은 목표 기간 뒤 예상 금액, 현재 순자산, 월 저축 목표, 현재 저축액 대비 추가 금액을 함께 보여준다.
- 조정 중인 월 저축 목표는 사용자와 프로필 입력 조합이 같은 경우에만 재진입 시 복원한다. 범위를 벗어나거나 다른 사용자·프로필의 임시값은 폐기한다.
- 목표 확정 요청에는 사용자가 선택한 월 저축 목표를 전달한다. 기존 목표안(`PLAN_1`, `PLAN_2`) 선택은 현재 공식 화면에서 사용하지 않는다.
- 목표 확정 시 온보딩 목표와 서비스의 목표를 함께 생성하고 프로필을 `COMPLETED`로 전환한다.
- 목표 확정 성공 후 홈으로 이동한다.
- 온보딩 완료 후 내 정보 수정으로 순자산·목표 기간·월 저축액을 갱신하면 확정된 목표를 다시 계산한다. 순자산을 목표 기준 금액으로, 월 저축액을 월 저축 목표로 반영하고 목표 금액을 `순자산 + 월 저축 목표 × 목표 기간`으로 재계산한다. 이 재계산에는 온보딩 슬라이더 상한(현재 월 저축액의 150%)을 다시 적용하지 않으며, 월 저축액이 월급을 넘지 못한다는 검증만 유지한다.

## 불변조건

- 확정된 목표 금액은 확정 시점 또는 이후 내 정보 수정 시점의 순자산, 월 저축 목표, 목표 기간으로 계산한 값과 같아야 한다.
- 목표 확정은 프로필 상태 변경과 서비스 목표 생성을 같은 처리 단위에서 완료한다.
- 이미 완료된 온보딩을 다시 확정하지 않는다.
- 온보딩 완료 여부는 서비스 목표 존재 여부와 일치해야 한다.

## 예외

- 프로필이 없거나 목표 계산에 필요한 값이 부족하면 미리보기와 확정을 거절한다.
- 공식 화면에서 프로필 질문값이 빠졌으면 설문 검토 화면으로 돌아가 보완한다.
- 미리보기 조회에 실패하면 목표를 임의 계산해 확정하지 않고 페이지 재진입을 안내한다.
- 목표 저장에 실패하면 현재 선택을 유지하고 다시 시도할 수 있게 한다.
- 서버에서는 이미 확정됐지만 클라이언트가 성공 응답을 받지 못해 재시도한 경우, 완료 충돌 응답을 완료 상태로 복구해 홈으로 이동한다.
- 서버의 목표 준비 조건은 공식 화면의 완료 조건보다 좁다. 이 차이는 [온보딩 main 구현 기준 결정](../../decisions/2026-08-25-onboarding-main-baseline.md)에 기록한다.
