# 마이페이지 계정 및 지원 정책

- ID: POLICY-MYPAGE-001
- 상태: active
- 적용 범위: 마이페이지의 약관·개인정보처리방침 조회, 문의, 앱 버전 확인과 탈퇴

## 규칙

- 마이페이지는 이용약관, 개인정보처리방침, 문의하기, 탈퇴하기를 제공한다.
- 이용약관과 개인정보처리방침은 인증 여부와 관계없이 조회할 수 있어야 한다.
- 문의하기는 사용 가능한 공식 카카오톡 오픈채팅 채널이 있으면 해당 채널을 제공하고, 사용할 수 없으면 이메일 문의 채널을 제공한다.
- 이메일 문의 채널을 제공할 때는 사용자가 주소를 직접 확인할 수 있어야 한다.
- 앱 버전은 네이티브 앱에서 유효한 버전 정보를 확인한 경우에만 표시한다.
- 탈퇴는 사용자가 확인 절차에서 명시적으로 동의한 뒤에만 실행한다.
- 탈퇴 처리 중에는 확인 창을 닫거나 같은 요청을 다시 보낼 수 없다.

## 불변조건

- 문의하기에는 카카오톡 오픈채팅 또는 이메일 중 하나 이상의 사용 가능한 문의 채널이 있어야 한다.
- 앱 버전을 확인할 수 없으면 빈 값이나 임의의 버전을 표시하지 않는다.
- 탈퇴 시 게스트 계정과 서버에 저장된 사용자 데이터는 즉시 삭제되며 복구할 수 없다. 단, 관계 법령상 보존 의무가 있는 정보는 정해진 기간 동안 보관한다.
- 애플리케이션 삭제는 탈퇴가 아니며 서버에 저장된 사용자 데이터를 삭제하지 않는다.
- 탈퇴가 성공한 경우 기존 사용자 상태를 계속 사용하지 않고 새 사용자 시작 화면으로 이동한다.

## 예외

- 공식 카카오톡 오픈채팅 채널이 없거나 사용할 수 없으면 이메일 문의로 대체한다.
- 일반 웹 환경이거나 앱 버전을 확인할 수 없으면 버전 정보 영역을 표시하지 않는다.
- 탈퇴에 실패하면 탈퇴 전 상태를 유지하고 실패 사실과 재시도 방법을 안내한다.
