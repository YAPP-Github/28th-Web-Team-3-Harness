# 미션 생성 입력 정책

- ID: POLICY-MISSION-001
- 상태: active
- 적용 범위: 추천 미션 생성에 필요한 카테고리·항목·소비 기준 입력

## 규칙

- 현재 클라이언트는 기존 다중 카테고리 미션 설문을 사용하지 않는다. 대화형 화면에서 카테고리, 줄이고 싶은 항목, 기준 빈도, 기준 금액을 순서대로 하나씩 입력한다.
- 카테고리는 식비·생활·취미 3개이며 교통은 제외한다.
- 서버 카탈로그가 노출하는 식비 항목은 배달음식·외식·카페·편의점이다.
- 서버 카탈로그가 노출하는 생활 항목은 의류·화장품·생활용품·미용이다.
- 서버 카탈로그가 노출하는 취미 항목은 수업&클래스·공연&전시&티켓이다.
- 기준 빈도는 1·3·5·7회 빠른 선택 또는 직접 입력으로 받으며 최종 허용 범위는 1~10회다. 기준 금액은 숫자로 직접 입력하며 허용 범위는 1~2,000,000원이다.
- 화면 질문의 기준 기간은 식비가 한 주, 생활·취미가 한 달이다. 입력값은 별도 환산 없이 생성 요청에 전달된다.
- 입력을 수정하면 수정한 단계부터 뒤의 답변을 초기화하고 다시 입력한다.
- 한 생성 요청은 카테고리 안의 항목 하나만 처리한다. 같은 항목으로 다시 생성할 수 있으며 항목별 생성 개수 제한은 없다.

## 불변조건

- 선택 항목은 서버 카탈로그에 활성 상태로 노출되고 선택 카테고리에 속해야 한다.
- 추천 미션 생성에는 생년월일·거주지역을 포함한 온보딩 완료 상태가 필요하다. 생성 화면에서 해당 프로필 값을 다시 질문하지 않는다.
- 기준 빈도와 기준 금액은 모두 정수이며 허용 범위를 벗어날 수 없다.

## 예외

- 카탈로그 조회에 실패하면 항목 선택 단계에서 다시 조회할 수 있어야 한다.
- 비활성 항목, 카테고리와 맞지 않는 항목, 범위를 벗어난 빈도·금액은 거절한다.
- 필수 온보딩이 완료되지 않으면 추천 미션 생성을 시작하지 않는다.
- 생활·취미 입력의 화면 기준 기간과 서버의 주간 목표 단위가 일치하지 않는다. 환산 규칙은 근거가 없으므로 확정하지 않고 [기준 기간 불일치](../exceptions.md#미션-소비-기준-기간-불일치)에 기록한다.
