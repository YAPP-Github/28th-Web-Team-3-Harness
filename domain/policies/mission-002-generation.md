# 추천 미션 생성 및 확정 정책

- ID: POLICY-MISSION-002
- 상태: active
- 적용 범위: 직접 템플릿 기반 후보·초안 생성, 생성 작업 조회, 초안 확정

## 규칙

- 현재 추천 미션 문구는 네이버 검색이나 AI 생성이 아니라 선택 항목에 등록된 활성 직접 템플릿에서 만든다.
- 생성 결과는 서로 다른 템플릿 3개다. 각 문구의 `{count}`에는 사용자가 입력한 기준 빈도를 그대로 넣는다.
- 모든 결과의 목표 횟수는 기준 빈도와 같고 목표 단위는 주당 횟수다. 절약 예상액은 기준 금액을 후보별로 그대로 사용하며 후보 수로 나누거나 1회 단가를 계산하지 않는다.
- 현재 클라이언트는 생성 작업을 만든 뒤 상태와 초안을 조회하는 경로를 사용한다. 서버는 직접 템플릿 초안 3개를 요청 처리 중 만들고 완료된 생성 작업을 반환하지만, 클라이언트는 상태 조회 계약을 유지한다.
- 클라이언트는 최소 로딩 표시 시간이 지난 뒤 생성 작업이 성공했고 초안을 조회할 수 있을 때 결과 화면으로 이동한다.
- 사용자는 초안 1~3개를 중복 없이 선택해 추천 미션으로 확정한다.
- 같은 생성 작업에 같은 초안 집합을 다시 확정하면 기존 결과를 반환한다. 다른 초안 집합으로 다시 확정하면 충돌로 거절한다.
- 별도 동기 미션 후보 조회는 저장 식별자가 없는 후보 3개를 즉시 반환하고 생성 작업·초안·미션을 저장하지 않는다. 현재 클라이언트 생성 화면은 이 조회를 사용하지 않는다.

## 불변조건

- 직접 템플릿은 항목별 후보 3개를 만들 수 있을 만큼 존재해야 한다.
- 생성 작업의 초안은 작업 소유자만 조회·확정할 수 있다.
- 확정할 초안은 같은 생성 작업에 속해야 하며 중복될 수 없다.
- 서버의 초안·확정 응답은 절약 예상액과 `단순 추정치로 정확하지 않을 수 있어요` 고지를 함께 제공한다.
- 생성 작업의 성공한 초안은 성공 시점부터 24시간 동안만 조회·확정할 수 있다.

## 예외

- 진행 중인 생성 작업과 입력이 같은 재요청은 기존 작업을 반환한다. 입력이 다르면 새 작업을 섞지 않고 충돌로 거절한다.
- 준비 중 작업의 초안 조회는 거절하고, 실패한 작업은 실패로 종료하며, 만료된 초안은 조회·확정할 수 없다.
- 생성 작업 상태를 일시적으로 조회하지 못해도 이전 상태가 있으면 즉시 실패로 확정하지 않고 다음 조회를 기다린다.
- 동기 후보 조회에는 확정용 식별자가 없으므로 해당 응답만으로 추천 미션을 저장할 수 없다.
- 현재 클라이언트 결과 화면은 서버가 제공한 비정확성 고지를 표시하지 않는다. 고지 노출 정책을 추론하지 않고 구현 차이로 남긴다.
